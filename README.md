# Pavillon Ratscher

Begehbares 3D-Modell des geplanten Gartenpavillons im Garten bei Ratscher (Thüringen): Entwurf in zwei Varianten, Bauphasen mit Kosten, 360°-Rundblicke, Bilder.

**Ansehen:** https://mynametouse.github.io/pavillon-ratscher/ (läuft im Browser, ohne Anmeldung).

Die Seite wird mit jeder neuen Modellversion aktualisiert. `plan.json` ist der veröffentlichte Planstand (Gebäude, Zäune, Möbel, Fassade).

Quellen und Lizenzen der verwendeten Modelle, Texturen und Geräusche stehen auf der Seite unter „Bilder“ → „Quellen und Lizenzen“.
